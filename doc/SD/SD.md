## 模块职责说明（仅 What）

### Client / API

* 作为系统的外部调用入口。
* 由外部程序或服务调用，用于：

  * 创建、启动、停止录画任务
  * 指定或变更输入源
  * 指定输出文件参数（路径、格式等）

### Recording Service

* 作为录画功能的统一入口与协调者。
* 接收来自 Client 的请求并进行语义层面的调度。
* 负责将一次录画请求拆解并分发给相关功能模块。

### Source Manager

* 负责管理所有输入源的生命周期。
* 维护当前有效的视频与音频输入源集合。
* 支持运行过程中输入源的动态添加与移除。

### Capture Processing

* 负责执行视频与音频数据的实际采集与基础处理。
* 从 Source Manager 获取输入源信息并进行数据采集。
* 向下游模块持续输出采集得到的数据。

### Subtitle Processing

* 负责基于音频数据生成字幕信息。
* 将音频内容转换为带时间信息的字幕条目。
* 字幕生成过程与采集过程解耦，允许延迟或失败。

### Output Management

* 负责录画结果的文件输出。
* 根据 Client 指定的参数生成对应格式的输出文件。
* 在未指定输出格式时，使用默认格式（MP4）。
